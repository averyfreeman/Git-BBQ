# Triage labels

Use the default Matt Pocock triage roles and identical GitHub label names.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | A maintainer must evaluate the issue. |
| Needs information | `needs-info` | Work is waiting for information from the reporter. |
| Ready for agent | `ready-for-agent` | Scope and acceptance criteria are clear enough for an agent to implement. |
| Ready for human | `ready-for-human` | The issue needs human implementation or judgment. |
| Won't fix | `wontfix` | The project will not action the request. |

When a skill refers to one of these roles, use the corresponding label exactly.
